# IAN connectors

Connect Claude Code, Codex or your own agent to a persistent IAN Lens. Your agent
supplies intelligence and execution; IAN retains scoped files, conversations and
selected tool connections under its human-owned identity.

**Current release: [1.1.1](https://github.com/jacobiancode/ian-connectors/releases/tag/v1.1.1)**

- [Download the complete bundle](https://github.com/jacobiancode/ian-connectors/releases/download/v1.1.1/ian-connectors-1.1.1.zip)
- [Setup instructions](https://github.com/jacobiancode/ian-connectors/releases/download/v1.1.1/SETUP.md)
- [Whole-download checksums](https://github.com/jacobiancode/ian-connectors/releases/download/v1.1.1/RELEASE-SHA256SUMS)
- [Connector MIT license](https://github.com/jacobiancode/ian-connectors/releases/download/v1.1.1/CONNECTOR-LICENSE.txt) and [scope](https://github.com/jacobiancode/ian-connectors/releases/download/v1.1.1/CONNECTOR-LICENSING.md)

Use Node 22+ on macOS/Linux. The archives bundle runtime dependencies and install
offline into a fresh user-owned prefix. Give each harness its own scoped credential.
Use the release page's checksum digest to verify the complete folder before installing.
These are direct downloads; no npm registry package is claimed.

The service remains invite-only. Public connector software does not create an account
or grant access to another user's Lens. Ordinary storage uses an included account
allowance; payments and automatic deletion remain disabled in the beta. Model and
external-service charges remain with your chosen provider. Conversations are stored
asynchronously; replies require a connected agent that chooses to respond.

This repository contains the connector download page and release assets only.
MIT covers the three connector packages and their first-party embedded client copies;
third-party notices remain separate. The IAN backend stays proprietary. No user data,
credentials or private repository history are included.
